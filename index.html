MODULE 03 / RULES

政策要点

成绩为主

综合成绩怎么算

综合成绩 = 学分加权平均成绩 + 素质评价成绩 × 0.1。素质评价加分上限 10 分，折算到综合成绩最多值 1 分——成绩排名决定资格，加分只决定资格线内的名次。

硬门槛

前 40% 与 120 学分

学分加权平均成绩须居本专业年级前 40%；前 3 学年已获学分不少于 120，且必须包含培养方案规定的前 3 学年全部必修课程；思想品德考核不合格不予推荐。

只看第一次

重修刷分救不了成绩

成绩统计前三学年所修全部课程（辅修不计），以第一次考试成绩计算，补考、重修成绩不计入，旷考记 0 分。所以每门课第一次考试就要当回事。

素质评价

四类加分只取最高一项

科研成果（论文 / 发明专利，须以安徽大学为第一署名单位）、竞赛获奖（国家级 A、B 类赛事与国际认定赛事）、创新项目（国家级大创合格结题）、社会实践（国际组织实习 3 个月以上，或志愿服务累计 100 小时以上）。同一类多项不累加，与直系亲属合作的成果不计入。

08 / STUDY ABROAD
Études à l'étranger

Study Abroad留学指南

路径选择、目的地对比、四年时间轴、申请材料与常见误区 · Study abroad guide

MODULE 01 / FOUR ROUTES

四条路径

ROUTE 01
联合培养 / 双学位

2+2、3+1 等形式，前段在国内、后段在合作院校完成学业，毕业取得双方学位。名额、绩点门槛与语言要求每年由学院发布，通常要提前一年准备。 Joint and dual-degree tracks such as 2+2 or 3+1: the later years are finished at the partner university and both institutions award a degree. Quotas, GPA cut-offs and language requirements are published each year and are usually planned a year ahead.

ROUTE 02
交换生

一学期或一学年的院际交换，学分按学校规定互认。名额少、竞争集中，一般在大二下或大三申请，需要盯紧国际交流部门的通知。 One-semester or one-year exchange, with credits transferred under the university rules. Places are few and competition is concentrated; applications usually open in the second half of year two or in year three, so watch the international office notices.

ROUTE 03
本科毕业直接申请硕士

最常见的一条路。大四上学期递交网申，次年秋季入学。美英港新多数项目集中在 9 至 12 月，部分采用滚动录取，越早递交越有利。 The most common route: apply in the first term of year four and start the following autumn. Most programmes in the US, UK, Hong Kong and Singapore open between September and December, and rolling admission rewards early applications.

ROUTE 04
语言课程 / 预科衔接

语言成绩暂时不达标时，部分院校提供语言课程，读完并通过内部考核后进入正课。要额外算清这部分的时间与费用，并确认通过率与升学条件。 When a language score falls short, some universities offer a pre-sessional course that leads into the degree on passing an internal assessment. Budget the extra time and cost, and check the pass rate and progression conditions.

四条路径的具体名额、门槛与时间由学院和合作院校每年发布，这里只做分类梳理；实际以学院通知与目标院校官网为准。
Quotas, thresholds and dates for each route are published yearly by the college and partner universities; this is only a classification, and the official notices remain authoritative.

MODULE 05 / PITFALLS

常见误区

  • 以为大一成绩不重要。多数项目按四年累计 GPA 评估，后两年权重更高，但补不回大一留下的窟窿。
  • 语言成绩留到最后。考位、出分、官方送分各要时间，至少提前半年开始，首考不理想还留有二战余地。
  • 文书套模板。招生官一年要读几百上千份，模板化的开头与结尾一眼就能认出来。
  • 只看综合排名。项目方向、课程设置、导师资源与就业去向，比名次更影响实际就读体验。
  • 忽略先修课要求。部分项目明确要求修过特定课程，缺课会在初审阶段被直接淘汰。
  • 作品集临时拼凑。数字媒体与设计方向，作品集的权重往往不低于 GPA，需要长期积累而不是突击。
  • 推荐信不跟进。老师事务繁忙，截止前两周提醒一次，并提前把材料与要点写清楚。
  • 签证与资金证明准备太晚。存款证明通常要求存满一定期限，递交前才想起会来不及。

LESSON CONTENT / 本课内容

From one memory cell to a running C program从一格内存到跑起来的 C 程序

2026.10.08 · CN / EN
STRUCTURE
Code and data share one memory程序与数据同存一室

冯·诺依曼结构的核心是"存储程序"：指令和数据放在同一个存储器里，CPU 逐条取指执行。今天所有通用的电脑、手机都还是这个框架。The stored-program idea: instructions and data share one memory, and the CPU fetches and runs them one at a time. Every general-purpose computer today still follows this design.

ADDRESS
The address is the key to pointers地址是理解指针的钥匙

内存被切成编了号的小格子：地址是门牌号，数据是屋里的东西。C 的指针就是"专门存门牌号的变量"。课堂原话：C 语言难就难在地址。Memory is a row of numbered cells: the address is the house number, the datum is what sits inside. A C pointer is simply a variable that holds a house number.

BUS
Three buses, three jobs三类总线各管一件事

地址总线报门牌、数据总线搬内容、控制总线发号令。地址总线的宽度决定这台机器最多能寻址多大内存。The address bus names the cell, the data bus carries the contents, and the control bus carries the commands. The width of the address bus caps how much memory can be addressed.

CYCLE
One instruction takes several ticks一条指令要好几拍

取指 → 译码 → 执行（访存 / 写回）。主频是节拍的快慢，不等于"每秒执行多少条指令"。Fetch, decode, execute (with memory access and write-back). The clock speed sets the tick rate, not the number of instructions per second.

BINARY
Two states are enough两种状态就够了

电路最容易稳定区分"通 / 断"两种状态，于是用 0 和 1 编码；1 字节 = 8 位，1 KB = 1024 字节。A circuit distinguishes two stable states most reliably, so information is encoded in 0s and 1s. One byte is eight bits; one kilobyte is 1024 bytes.

HIERARCHY
Fast, small, expensive — and vice versa越快越小越贵

寄存器 → 缓存 → 内存 → 外存。越靠近 CPU 越快、越小、越贵；程序只显式管内存和外存，缓存由硬件自动调度。Registers, cache, main memory, then storage. The closer to the CPU, the faster, smaller and dearer. Programs manage memory and storage explicitly; the cache is handled by hardware.

Von Neumann architecture and the five parts冯·诺依曼结构与五大部件

1945 年，冯·诺依曼在 EDVAC 报告草案里提出"存储程序"的机器模型：程序本身也当成数据存进存储器。整台机器拆成五个部分——运算器（算术与逻辑运算）、控制器（指挥时序）、存储器（存放指令与数据）、输入设备、输出设备。今天说的 CPU，就是运算器加控制器，再加寄存器。

In the 1945 EDVAC draft, von Neumann set out the stored-program model: the program itself is stored as data. The machine has five parts — arithmetic unit, control unit, memory, input and output. What we now call the CPU is the arithmetic unit plus the control unit, together with registers.

这套设计带来的最大副作用是冯·诺依曼瓶颈：指令和数据共用一条通道往返 CPU 与内存，CPU 再快也要等数据。现代计算机用缓存、流水线和多核来缓解，但结构本身没有变——这正是课堂上那句话的意思："很多软件、很多大模型出来了，但是计算机底层的东西没有变。"

The price of this design is the von Neumann bottleneck: instructions and data share one path between CPU and memory, so a fast CPU still waits for data. Caches, pipelines and multiple cores soften it, but the structure itself has not changed — which is exactly what the lecturer meant by "plenty of software and big models have appeared, yet the fundamentals of the computer have not changed".

Addresses versus data地址与数据：差一个方括号

内存像一排编号的抽屉。0x20 是抽屉编号（地址），抽屉里放的东西才是数据。同一个数字既可能是地址也可能是数据，全靠指令的上下文来区分——写汇编时用不用方括号，写 C 时用不用 *，说的就是这件事。这正是指针最容易绕晕人的地方。

Memory is a row of numbered drawers. 0x20 is the drawer number (an address); the value inside is the data. The same number can be either one, and only the instruction's context tells them apart — that is what square brackets in assembly and the asterisk in C are for, and it is exactly where pointers confuse beginners.

  • 十六进制的两种写法：C 语言写 0x1A；汇编与调试器里常见后缀写法 1Ah。两种都对，但不要混着写。Two notations: 0x1A in C, and 1Ah as a suffix in assembly or debuggers. Both are valid — just do not mix them in one expression.
  • 为什么偏爱十六进制：一个十六进制位恰好等于四个二进制位，一个字节写成两个十六进制位（如 0x1A = 0001 1010），比一串 0 和 1 好读太多。One hex digit is exactly four bits, so a byte is two hex digits — far easier to read than a run of 0s and 1s.
  • C 里的地址：int x = 42; int *p = &x; —— & 取地址，* 按地址取内容。指针变量本身也占内存，大小由地址总线位宽决定：32 位机器 4 字节，64 位机器 8 字节。In C, & takes an address and * dereferences it. A pointer variable is itself stored in memory, and its size follows the address width: four bytes on a 32-bit machine, eight on a 64-bit one.
  • 数组为什么能用指针访问：数组名会退化成首元素的地址，p + 1 不是"加一个字节"，而是"跳到下一个同类型元素"。An array name decays to the address of its first element, and p + 1 moves by one element rather than one byte.

The program counter and clock ticksPC 指令计数器与时钟节拍

PC（Program Counter，程序计数器）里存的是下一条指令的地址。取完一条，PC 自动加上这条指令的长度，于是程序顺着内存往下走——这就是"顺序执行"。一旦遇到跳转、分支、循环、函数调用，本质都是改写 PC：把它改成别处的地址，程序就从那里继续。

The program counter holds the address of the next instruction. After each fetch it advances by the instruction's length, which is what makes execution sequential. Jumps, branches, loops and function calls all amount to rewriting the PC.

时钟节拍是计算机的心跳：主频 1 Hz 表示每秒一拍，3.0 GHz 表示每秒 30 亿拍。但一条指令通常要好几拍（取指、译码、执行各占若干拍），所以主频不能直接换算成"每秒多少条指令"。现代 CPU 再靠流水线（像流水线那样把多条指令的不同阶段叠着做）、乱序执行和多核把吞吐拉上去。

The clock is the heartbeat: 3.0 GHz means three billion ticks a second. One instruction usually takes several ticks, so clock speed is not a direct measure of instructions per second. Pipelines, out-of-order execution and multiple cores are what raise throughput.

Binary, bits and bytes二进制、位与字节

为什么是二进制？因为电子器件最容易、最便宜、最抗干扰地稳定区分两种状态：通与断、高电平与低电平。要区分十种状态，器件就得做得很精密，成本和出错率都会上去。二进制还和逻辑门（与、或、非）天然对应，这也是整个数字电路的基础。

Why binary? Because a circuit distinguishes two stable states — on and off, high and low — cheaply and reliably. Ten states would demand far more precision. Binary also maps naturally onto logic gates, which is the foundation of all digital circuits.

1 · Bits, bytes and how many states you get1 · 位、字节与状态数量

位（bit）是最小单位，只能取 0 或 1；字节（byte）固定由 8 位组成，是存储与处理的通用基本单位。n 位能表示 2ⁿ 种不同组合，所以一个字节有 2⁸ = 256 种状态，覆盖从 00000000 到 11111111 的全部组合。

难度往上走一层：为什么偏偏是 8 位？这不是数学结论，而是工程折中——既能容纳 128 个 ASCII 符号（再加一位作校验位），又是可寻址的最小单位。更重要的是"字长"（word size）：它决定一次能并行处理多少位、指针占几字节、进程能寻址多大空间。32 位机器指针 4 字节、最多 4 GiB；64 位机器指针 8 字节。

A bit holds 0 or 1; a byte is exactly 8 bits, so it has 2⁸ = 256 states. Eight is an engineering compromise, not a mathematical necessity: it fits the 128 ASCII symbols plus a parity bit, and it is the smallest addressable unit. Word size is the deeper idea — it fixes pointer width, the number of bits processed at once, and the addressable space (4 GiB at 32 bits, far more at 64).

3 · Number bases, and how to read them3 · 进制体系与读法

十进制是人类日常计数体系，二进制是机器的原生表示，十六进制是人机之间的"压缩格式"——4 位二进制恰好等于 1 位十六进制。十六进制以 16 为基数，A–F 对应十进制的 10–15；书写时有三种约定：后缀 H（12AH）、前缀 0x（0x12A）、或下标 (12A)₁₆。

难度往上走一层：小数在二进制里往往不精确。 整数可以精确表示，但形如 0.1 的十进制小数展开成二进制是无限循环的，任何有限位宽的浮点类型都只能存它的近似值。这就是 0.1 + 0.2 != 0.3 的真正原因——不是语言有 bug，而是二进制表示本身装不下。C 里比较浮点数要用误差范围（如 fabs(a-b) < 1e-9），不能直接用 ==。

Integers are exact; most decimal fractions are not. 0.1 in binary is an infinitely repeating expansion, so any finite-width floating-point type stores only an approximation — that, and not a language bug, is why 0.1 + 0.2 != 0.3 in C. Compare floating-point values with a tolerance instead of ==.

4 · Signed numbers and two's complement4 · 有符号数与补码

8 位有符号数的最高位是符号位：0 表示正数，1 表示负数。负数用补码存储，规则是"取反加一"。补码让加法电路同时完成减法：a − b 就写成 a + (−b)，把最高位的进位丢掉即可。

两处需要更正原笔记的地方：第一，原笔记说"计算机底层无减法电路"，更准确的说法是——算术逻辑单元通常用"加补码＋忽略进位"实现减法，而不是完全没有减法能力；第二，补码是非对称的：8 位补码范围是 −128 到 127，−128 没有对应的正数，这一点在写 abs() 或取负时要特别小心（对 −128 取负会溢出）。

In an 8-bit signed value the top bit is the sign, and negatives are stored in two's complement ("invert and add one"), which lets one adder circuit perform subtraction: a − b becomes a + (−b) with the carry out of the top bit discarded. Two corrections to the original notes: an ALU does perform subtraction — it does so via two's complement rather than lacking the capability; and two's complement is asymmetric, so the 8-bit range is −128…127 and −128 has no positive counterpart (negating it overflows).

5 · Character encoding: ASCII and Unicode5 · 字符编码：ASCII 与 Unicode

ASCII 是美国标准信息交换码，共 128 个符号，占 7 位二进制，存储时最高位补 0 凑满一个字节。要背熟的对应关系：'A' = 65 = 0x41，'a' = 97 = 0x61，'0' = 48 = 0x30；字母与数字的码值连续递增。控制符里有换行 LF = 10（C 里写作 \n）、退格 BS = 8。

两处需要补严的地方：ASCII 的可打印字符是 0x20–0x7E，0x00–0x1F 与 0x7F 是不可打印的控制符；另外常说的"扩展 ASCII"（0x80–0xFF，如 Latin-1）并不是 ASCII 标准，把它和 ASCII 混为一谈会在处理中文时踩坑。

Unicode 给每个符号分配唯一代码点（前缀 U+，如汉字"中"是 U+4E2D），但代码点只是编号，实际怎么存要看编码格式：UTF-8 是最主流的格式，一个符号占 1–4 字节，英文仍是 1 字节，汉字通常 3 字节。UTF-8 的优点是向后兼容 ASCII。

字符转数字的经典技巧：'7' - '0' 得到整数 7。成立的前提是数字字符在编码表里连续排列——这个前提在 ASCII/EBCDIC 之间不同，所以严格说是实现依赖的技巧。

Standard ASCII is a 7-bit code covering 128 symbols, stored with a leading 0 to fill a byte; printable characters run 0x20–0x7E while 0x00–0x1F and 0x7F are control codes. "Extended ASCII" (0x80–0xFF, e.g. Latin-1) is not part of the standard. Unicode assigns each symbol a code point (U+4E2D for 中), but storage is decided by the encoding: UTF-8 uses 1–4 bytes per symbol, one byte for English letters and typically three for Chinese, and stays backward compatible with ASCII. The idiom '7' - '0' yields 7 only because digit characters are contiguous — a property that is implementation-dependent.

6 · Memory layout and variables6 · 内存分区与变量

运行中的程序，内存大致分成四块：代码段（机器指令，只读）、数据段（已初始化的全局与静态变量）、BSS（未初始化的全局与静态变量，运行时清零）、堆（程序员用 malloc/free 主动申请与释放）、栈（函数调用时自动增长，存放局部变量、返回地址与寄存器现场）。

这里要更正原笔记的划分方式：把数据区简单分成"全局变量区、堆、栈"不够准确，因为栈并不属于数据区，而且全局变量还要区分已初始化（data）与未初始化（bss）。更关键的是——栈和堆的"增长方向"相反，两者相向生长，中间是尚未使用的空闲区。

内存按字节编址：每个字节有唯一地址，像房间门牌号。C 语言采用按名存取——你写变量名，编译器负责翻译成地址；&x 取到的是变量首地址。32 位系统的寻址空间是 2³² 字节 = 4 GiB，64 位系统主流但嵌入式里仍有 32 位。

难度往上走：基础类型的字节数并不是标准固定的。sizeof(char) 恒为 1，但 int 在常见平台上 4 字节、double 8 字节只是"普遍如此"。标准只给出最小值约束，所以跨平台代码要用 sizeof、<stdint.h> 里的 int32_t 这类定宽类型，而不是假设字节数。

A running program's memory is usually laid out as text (read-only code), data (initialised globals and statics), bss (zero-initialised globals and statics), heap (explicitly requested with malloc/free) and stack (grown automatically by calls, holding locals, return addresses and saved registers). The original notes folded the stack into the data area, which is not accurate, and the heap and stack in fact grow towards each other. Memory is byte-addressed, and C uses name-based access: you write x, the compiler produces the address, and &x yields the first byte's address. Sizes of the basic types are not fixed by the language — only sizeof(char) is guaranteed to be 1 — so portable code uses sizeof and fixed-width types such as int32_t.

7 · From source code to a running program7 · 从源代码到可执行程序

C 程序不是一步变成可执行文件的。真实流程是四个阶段：预处理（展开 #include、#define，去掉注释）、编译（把 C 翻译成汇编）、汇编（把汇编翻译成机器码，得到目标文件 .o）、链接（把目标文件与库函数拼成一个可执行文件）。

原笔记把这一步说成"编辑器→编译器→链接器"，漏了预处理与汇编。用 gcc 一行命令编译时，这四步是自动串起来的；但理解它们各自在做什么，才能在报错时判断错误来自哪一层——"undefined reference"是链接期错误，"expected ';'"是编译期错误，而宏展开出错则是预处理阶段的问题。

标准程序结构是"头文件 + main 主函数 + 核心语句"。最简单的 Hello World：

#include <stdio.h> int main(void) { printf("Hello, world\n"); return 0; }

A C program does not become an executable in one step: the preprocessor expands includes and macros, the compiler translates C into assembly, the assembler turns that into an object file, and the linker joins object files with libraries. The original notes skipped the first and third stages. Knowing the stages is what lets you tell where an error comes from — "undefined reference" is a link-time error, a missing semicolon is compile-time, and a broken macro fails during preprocessing.

3 · Compiled or interpreted — and what "intermediate code" really means3 · 编译型与解释型：也说说"中间代码"到底是什么

把高级语言变成机器能执行的东西，有两条路线：

解释型：逐行翻译并立即执行——课堂上类比为"现场同声传译"。改一行就能立刻跑，但每次运行都要重新翻译。 编译型：先把整个程序翻译成可执行文件，再运行——类比为"把整本书一次翻完"。翻译慢，但运行快，而且编译一次可以运行很多次。

Interpreted languages translate line by line at run time — simultaneous interpretation. Compiled languages translate the whole program once into an executable — translating a book. C is compiled.

原笔记这里有一处需要更正：笔记说"编译是先生成中间代码再运行，设置中间代码是为保障跨机器运行的一致性"。这个说法把两件事混在了一起：

  • C 的编译流程里确实会产生"中间产物"，但那是目标文件（.o），不是"运行用的中间代码"——机器码最终还是落到具体平台上的。
  • "中间代码"这个词通常指编译器内部的中间表示（IR），或 Java／C# 那种字节码。C 程序运行时不依赖任何中间代码，它跑的就是本机机器码。
  • 跨平台靠的不是中间代码，而是分别编译：同一份 hello.c，在 Windows 上要重新编译成 hello.exe，在 Linux 上要重新编译成 ELF 可执行文件。源代码可移植，编译出来的二进制不可移植——这是理解"C 的可移植性"的关键。

A correction: C's build does produce an intermediate artefact — the object file (.o) — but that is not "intermediate code the program runs on". The term usually means the compiler's internal intermediate representation, or bytecode as in Java. A C program runs as native machine code; portability comes from recompiling the source for each platform, not from an intermediate layer. Source is portable, binaries are not.

5 · How a C program is put together5 · 一个 C 程序由什么构成

C 程序由多个可以互相调用的函数组成，支持模块化开发。函数分两类：开发者自己写的自定义函数，和语言自带的标准库函数。

标准库的头文件数量：课堂上说"C 标准库共 15 个头文件"——这个数字对应的是 C89/C90（assert、ctype、errno、float、limits、locale、math、setjmp、signal、stdarg、stddef、stdio、stdlib、string、time）。需要补一句：C99 之后又新增了 stdbool.h、stdint.h、complex.h 等，各编译器还有自己的扩展头文件。所以"15 个"是那一版标准的数量，不是"C 只有 15 个"。常用的输入输出、字符判断、数学运算、字符串处理这几类，定义都在教材附录 C。

The standard library has 15 headers in C89/C90; C99 added more (stdbool.h, stdint.h, complex.h …) and compilers add their own extensions. So "15" is a snapshot of one standard, not the whole story.

注释：/* … */ 是多行注释，// 是单行注释。原笔记说"注释会被编译系统过滤"——更准确的说法是在预处理阶段就被删掉，根本不会进入编译。另外 // 这种写法是 C99 才正式纳入标准的（C89 里它不合法），这一点考试里偶尔会被问到。

Comments are removed during preprocessing, before compilation proper. The // form only became standard in C99.

函数的构成：定义一个函数要明确三件事——返回值类型、函数名、参数类型。课堂用"加工机器"和"食堂窗口打饭"来类比：送入原料（参数），产出成品（返回值）。这就是所谓 IPO 逻辑——输入（Input）、处理（Process）、输出（Output）。写程序前先想清楚这三步，比急着敲代码有效得多。

代码规范（老师特别强调）：变量声明与业务代码之间空行分隔；一行只写一条语句；合理使用空行提升可读性。这些空行不占磁盘空间，却直接决定别人（和几个月后的你）能不能读懂。另外课堂提到一个能显著提速的小技巧：用 Home / End 键在行首行尾之间跳转。

Standard practice the lecturer insisted on: blank lines between declarations and logic, one statement per line. Blank lines cost no disk space and decide whether the code can be read later. Home/End jump to the start and end of a line.

3 · What main really is3 · main 到底是什么

课堂上的说法是"main 是 C 语言的预定义标识符，但不是保留字"。前半句需要更正——而且更正之后，你对 C 的理解会更准。

The lecture called main "a predefined identifier that is not a keyword". The second half is right; the first half is not, and correcting it sharpens the picture.

  • "预定义标识符"在 C 标准里是一个专有名词，指的是 __FILE__、__LINE__、__DATE__、__TIME__、__func__、__STDC__ 这些由编译器自动设定的名字（C11 §6.10.8）。main 不在这个名单里。
  • main 也不是库函数，标准库头文件里没有它的声明。
  • main 的真正身份是：标准规定的程序入口函数名（C11 §5.1.2.2.1）。程序启动时，运行环境按这个名字去调用它，所以它必须叫 main，不能改名。
  • 因此下面的推论就顺理成章了：一个程序里有且只有一个 main（否则链接器不知道调哪个）；Main、MAIN 都是普通函数名，能编译，但不会被当作入口。
  • 严格地说，"程序从 main 的第一条语句开始执行"也有前提：在 main 被调用之前，运行环境已经完成了静态存储期对象的初始化等工作。对入门阶段可以先记住结论，但别把它当成"第一件事就是 main"。

main is neither a keyword nor a predefined identifier in the standard's sense; it is the entry-point function name the standard requires. That single fact explains why there can be exactly one, why Main is legal but useless as an entry point, and why "execution starts at main" is a simplification — static initialisation happens first.

4 · Functions: a header, a body, and one rule about semicolons4 · 函数：一个头、一个体，以及一条分号规则

函数分成函数头和函数体两部分，这是本课最实用的一张骨架图：

int add(int a, int b) /* 函数头：返回值类型 int · 函数名 add · 参数列表 (int a, int b) */ { int sum = a + b; /* 函数体：一条一条以分号结尾的可执行语句 */ return sum; }

函数头由三样东西构成：返回值类型、函数名、参数列表。课堂用"食堂窗口打饭"和"绞肉机"作类比：把原料（参数）递进去，产出成品（返回值）。参数的个数、类型和顺序决定了这个"窗口"接受什么；返回值类型决定了它递回来什么。写函数之前先想清楚这三件事，比敲代码重要。

函数体是一串语句，默认从上到下顺序执行。每条可执行语句末尾必须是一个英文分号——中文分号 ； 是初学者最高频的错误之一，因为屏幕上几乎看不出区别。另外，函数头后面不能加分号：写成 int add(int a, int b); 就成了"函数声明"而不是定义。

A function has a header (return type, name, parameter list) and a body (statements, each ending in a semicolon). Think of it as a machine: parameters in, return value out. Note the trap — a semicolon straight after the header turns a definition into a mere declaration.

调用过程（配合演示二看）：执行到函数调用时，系统先把"下一条指令的位置"（返回地址）记录下来，再跳到被调函数去执行；被调函数返回时，按记录的地址回到原处继续。这就是为什么函数可以嵌套调用而不会"忘了自己在哪"。

On a call the system records the return address, transfers control, and comes back to the recorded position when the callee returns. That is what lets calls nest without losing the thread.

5 · printf, arguments, and commands that start with #5 · printf、参数，以及以 # 开头的命令

课堂把 printf 讲成一台"绞肉机"：把原料（带双引号的格式化数据等参数）从进料口送进去，加工之后从"标准输出设备"（通常是显示器）出来。这个类比抓住了两件事——printf 是函数，所以它有参数；它的作用是把东西送到标准输出，而不是把结果算出来。

printf is a function, therefore it takes arguments; and its job is to send text to the standard output device, not to compute anything. The lecture's mincer analogy captures both points.

预处理命令：以井号 # 开头，例如 #include <stdio.h> 和 #define PI 3.14159。课堂说"它不属于 C 语言本身的组成部分"——这个说法来自教材，需要补一句才准确：

  • 预处理确实是 C 标准的一部分（C11 §6.10 专门规定它），所以说它"不属于 C"容易引起误解。
  • 更准确的说法是：预处理发生在编译之前，它的语法与 C 语言本身不同。#define 做的是纯文本替换，编译器看到的已经是替换后的代码。
  • 由此推出一个必须记住的后果：#define 定义的"常量"没有类型、没有作用域、不参与类型检查。真正常量应该优先用 const float PI = 3.14159f;。

Preprocessing is part of the C standard, but it runs before compilation and uses its own syntax. #define performs pure textual substitution, so a macro "constant" has no type, no scope and no type checking — prefer const for real constants.

6 · Escape sequences and where the cursor lands6 · 转义序列，以及光标最后停在哪

反斜杠开头的转义序列用来表达"打不出来"或者"有特殊含义"的字符。\n 是换行，课堂用它讲了一个很值得琢磨的细节：同一个 \n，放在内容前面和后面，输出内容的行数一样，但程序结束时光标停的位置不同。

写法屏幕上发生什么光标最后停在哪

常用转义序列（拓展）：\n 换行 · \t 制表（对齐表格常用） · \\ 输出一个反斜杠 · \" 输出双引号 · \0 空字符（字符串结束标志，第 6 课会用到） · \r 回车（回到行首）。

An escape sequence writes characters that cannot be typed directly. The lecture's point is worth keeping: the same \n before or after the text produces the same number of lines but leaves the cursor in a different place — and the cursor position is part of the program's visible output.

7 · Data types and literal values7 · 数据类型与字面值

课堂给的定义很准：数据类型是一类数据的名称，本质是"一个值的集合"加上"可以作用在这些值上的操作集合"。这句话的每一半都有用：值的集合决定了它能表示什么（int 装不下 10.5），操作的集合决定了它能做什么（整数能取余 %，浮点数不能）。

A data type is a name for a class of data: a set of values plus the set of operations defined on them. The first half decides what can be stored; the second decides what can be done.

分类：C 的内建基本类型先分两大类——整数类型（char、short、int、long 及各自的 unsigned 版本）和浮点类型（float、double、long double）。字符型属于整数家族，这一点第 9 节会展开。

字面值（literal）：直接写在代码里、值确定的东西。2 * 3.1416 * r 里的 2 和 3.1416 就是字面值；而 r 是变量，不是字面值。字面值也带类型：2 是 int，2.0 是 double，2.0f 是 float，2L 是 long——这个区别在第 8 节的整除陷阱里会立刻显出威力。

A literal is a value written directly in the source. Literals have types too: 2 is an int, 2.0 a double, 2.0f a float, 2L a long — which matters immediately in the next section.

一处更正：课堂把 Bool 类型列为 C 的数据类型。C 语言本身没有内建的布尔类型；C99 起要靠 #include <stdbool.h> 得到 bool（本质是宏），直到 C23 才把 bool 变成真正的关键字。

7 / 2 = 3 7 % 2 = 1 -7 / 2 = -3 -7 % 2 = -1 /* 向零截断，不是 -4 */ 7.0 / 2 = 3.5 /* 有一边是浮点，就走浮点除法 */

单引号包一个字符，双引号包一串字符——'A' 是字符，"A" 是字符串。它们在 C 里是不同的类型，不能混用：'A' 占 1 字节，"A" 实际占 2 字节（多出来的那个是字符串结束标志 '\0'，第 6 课细讲）。

字符在内存里存的是编码值。标准 ASCII 用 7 位表示 0–127：大写字母 A–Z 是 65–90，小写 a–z 是 97–122，数字 0–9 是 48–57。同一个字母的大小写相差 32——这不是凑巧，而是 32 = 2⁵，二进制里只差第 5 位（从 0 开始数）。所以

'a' - 'A' = 97 - 65 = 32 /* 只翻转了一个二进制位 */ '7' - '0' = 55 - 48 = 7 /* 字符数字 → 数值，这个转换天天在用 */

纠错两处：其一，原笔记说"ASCII 实际为 7 位，字节最高位补 0"——标准 ASCII 确实只定义 0–127，但在真实系统里，第 8 位历史上被用作奇偶校验位，如今 128–255 又被各种扩展编码（ISO-8859、Windows 代码页）占用，不能一概说"最高位一定是 0"。其二，笔记把字符型说成"属于整数类型"——更精确的说法是：char 是整型家族（integer types）的一员，可以参与算术运算，但 C 标准里 char、signed char、unsigned char 是三种不同的类型，别把它们当同一个。

Standard ASCII defines 0–127, but the eighth bit is not always zero in practice: it was historically a parity bit and bytes 128–255 are used by extended encodings. And char, signed char and unsigned char are three distinct types, though all belong to the integer family.

一个可移植性要点（拓展）：C 标准保证数字字符 0–9 的编码是连续的，所以 '7' - '0' == 7 在任何符合标准的实现上都成立；但它不保证字母连续，所以 'a' - 'A' == 32 只是在 ASCII 及其兼容编码（包括 UTF-8）下成立。EBCDIC 机器上就不成立——想写真正可移植的大小写转换，应当用 toupper() / tolower()。

The standard guarantees the ten digits are contiguous, so '7' - '0' == 7 is portable. It does not guarantee anything about letters: 'a' - 'A' == 32 holds on ASCII-compatible systems (including UTF-8) but fails on EBCDIC. Use toupper/tolower for portable case conversion.

5 · Inside a float: the IEEE 754 layout5 · 浮点数的内部：IEEE 754 的位布局

课堂给出了位分配，这是理解"为什么 0.1 不精确"的入口：

float (32 位) = 1 位符号 + 8 位指数 + 23 位尾数 double (64 位) = 1 位符号 + 11 位指数 + 52 位尾数

这相当于二进制的科学计数法：± 1.xxxxx × 2^e。符号位管正负，指数位管大小（存的是"指数 + 偏移量"），尾数位管精度。所以有效数字的位数由尾数位数决定——23 位尾数对应约 7 位十进制（log₁₀2²³ ≈ 6.9），52 位对应约 16 位（log₁₀2⁵² ≈ 15.7）。这就是表格里那两个数字的来源。

A float is binary scientific notation: sign, biased exponent, mantissa. The mantissa width sets the precision — 23 bits give about 7 decimal digits and 52 bits about 16, which is where the table's numbers come from.

为什么 0.1 存不准：0.1 的二进制展开是 0.0001100110011…（1100 无限循环）。尾数只有 23 位，写到第 24 位就必须截断，于是存进去的是一个很接近 0.1 但不是 0.1 的数。这不是 C 的缺陷，是所有用二进制定点尾数的语言共同面对的事实——十进制里 1/3 也写不完。

由此得到三条实用规则：不要用 == 比较两个浮点数（改用 fabs(a-b) < 1e-6）；不要用浮点数做金额计算（用整数分或定点数）；0.1f + 0.2f != 0.3f 是正常现象，不是编译器坏了。

0.1 has an infinite binary expansion, so the mantissa truncates and the stored value is merely close. Hence: never compare floats with ==, never use them for money, and 0.1f + 0.2f != 0.3f is expected behaviour.

6 · sizeof: an operator, not a function6 · sizeof：是运算符，不是函数

课堂特意强调：sizeof 是 C 语言的保留字（运算符），不是函数库里的函数。它返回指定类型、变量或表达式占用的字节数。两种写法要分清：

两个容易忽略的点：其一，sizeof 的结果类型是 size_t，是无符号整型，打印要用 %zu（用 %d 在 64 位平台上是未定义行为）。其二，sizeof 在编译期就求值（变长数组除外），所以 sizeof(x++) 不会真的自增——它不求值表达式。

sizeof is a keyword. Parentheses are optional for variables but required for type names. Its result is size_t, so print it with %zu; and it does not evaluate its operand, so sizeof(x++) never increments x.

7 · Byte order: little endian and big endian7 · 字节序：小端与大端

同样的 32 位二进制内容，放进内存时"先放哪个字节"是一个约定，这个约定就叫字节序。

小端（little endian）：低位字节放在低地址。x86 / x64 以及绝大多数 ARM 默认如此——课堂说的"PC 端默认小端"指的就是这个。 大端（big endian）：高位字节放在低地址。网络协议（TCP/IP）统一采用大端，所以叫"网络字节序"。

这里要更正课堂表述的主体：字节序是处理器体系结构的属性，C 语言标准完全不规定字节序。所以不能写"PC 端 C 语言默认小端"，准确说法是"x86/x64 处理器采用小端，因此在这些平台上运行的程序是小端"。某些 ARM 处理器甚至可以运行时切换字节序。

Endianness belongs to the processor architecture, not to C. x86/x64 is little endian, which is why PCs are; network protocols standardise on big endian. The C standard is silent on the matter.

为什么这件事要紧：只要数据不离开本机（同一进程、同一平台），字节序对你是透明的。一旦跨越边界——写二进制文件、走网络、和别的语言或别的架构交换数据——就必须约定字节序，否则 0x12345678 会被读成 0x78563412。判定的经典写法是把一个已知整数按字节打印出来看。

Endianness matters the moment data crosses a boundary: binary files, networks, or another architecture. Within one process on one platform it is invisible.

The intuitive definition朴素定义与极限到底在看什么

当自变量 x 充分接近 a（但 x ≠ a）时，函数值 f(x) 可以任意接近某个常数 L，就说 x 趋于 a 时 f(x) 的极限是 L，记作 lim (x → a) f(x) = L。这个定义只关心"趋近的趋势"，不关心 a 点本身。

If f(x) can be made arbitrarily close to a constant L by taking x sufficiently close to a (but not equal to a), the limit of f at a is L, written lim (x → a) f(x) = L. Only the trend matters, not the point a itself.

One-sided limits and when a limit exists单侧极限与极限存在的条件

左极限指 x 从小于 a 的方向趋近 a，记 x → a⁻；右极限指 x 从大于 a 的方向趋近 a，记 x → a⁺。在一维情形下，函数在 a 点极限存在，当且仅当该点的左右极限都存在且相等。

The left limit uses x approaching a from below (x → a⁻); the right limit approaches from above (x → a⁺). In one dimension, the limit at a exists exactly when both one-sided limits exist and are equal.

在二维或更高维空间，趋近某点的方向有无穷多个，"左右两侧"的判定不再适用，必须沿任意路径都趋于同一个值，极限才存在。

In two or more dimensions there are infinitely many directions of approach, so the two-sided test no longer applies; every path must lead to the same value.

When a limit does not exist极限不存在的典型情形

课堂给出的典型例子是 sin(1/x)：当 x 趋于 0 时，函数值在 -1 到 1 之间无限加快地震荡，自变量的极小变化就会让函数值完成多次周期震荡，不存在统一的趋近目标，因此该点极限不存在。

The lecture's standard example is sin(1/x): as x approaches 0 the value oscillates ever faster between -1 and 1, so there is no single value being approached and the limit does not exist.

补充：证明思路是构造两条都趋于 0 的序列，看它们对应的函数值。x(n) = 1/(2nπ + π/2) → sin(1/x(n)) = 1 x(n) = 1/(2nπ) → sin(1/x(n)) = 0两条序列的函数值极限不同，所以极限不存在。这也是后续用序列刻画极限（海涅定理）的伏笔。

The usual proof takes two sequences that both tend to 0 but give different values of sin(1/x), so no limit exists.

Neighbourhoods, infinite limits and vertical asymptotes邻域、无穷极限与垂直渐近线

点 a 的 δ 邻域指以 a 为中心、δ 为半径的开区间 (a-δ, a+δ)；去掉中心点 a 后就是去心邻域，写作 0 < |x - a| < δ。讨论极限时用的正是去心邻域，因为 a 点本身不参与。

The δ-neighbourhood of a is the open interval (a-δ, a+δ); removing a leaves the punctured neighbourhood 0 < |x - a| < δ, which is what limits actually use.

当 x 充分接近 a 时，如果 |f(x)| 可以大于任意给定的正数 M，就说 x 趋于 a 时 f(x) 的极限为无穷，记作 ∞ 或 -∞。要紧的是：无穷不是实数，它只是刻画函数变化趋势的符号。

If |f(x)| can exceed any given positive number M once x is close enough to a, the limit is said to be infinite, written ∞ or -∞. Infinity is not a real number; it is a symbol describing a trend.

Limit laws and a worked example补充：极限运算法则与例题

以下为补充内容，课堂只做直观引入；正式证明会在严谨定义之后给出。

设 lim f 与 lim g 都存在，则四则运算可以直接拆分：

lim (f ± g) = lim f ± lim g lim (f · g) = lim f · lim g lim (f / g) = lim f / lim g （要求 lim g ≠ 0）

If both limits exist, sums, products and quotients can be split term by term, provided the denominator's limit is not zero.

遇到 0/0 型未定式时，不能直接"约掉 0"，要先化简：常用手段是因式分解、分子有理化、通分。例题：

lim (x → 3) (x² - 9)/(x - 3) = lim (x → 3) (x + 3) = 6

后续课程会反复使用的两个标准极限：

lim (x → 0) sin x / x = 1 lim (n → ∞) (1 + 1/n)^n = e

提醒：运算法则的前提是极限存在；0/0 只是"未定"，需要继续化简，而不是无意义或等于 0。

From intuition to rigour: the ε-δ definition从直观到严格：极限的 ε-δ 定义

课堂用"x 充分接近 a 时 f(x) 充分接近 L"刻画极限，这在应用上够用，却无法支撑证明——"充分"是程度副词，不是数学对象。要使它成为可以运算、可以推理的定义，必须把两个"充分"分别量化：把"f(x) 接近 L 到什么程度"交给任意给定的 ε，把"x 要离 a 多近"换成存在性的 δ。

The lecture's phrasing — "f(x) gets close to L when x gets close to a" — is fine for applications but cannot support proof, because "close" is a degree adverb rather than a mathematical object. Making it rigorous means quantifying both: an arbitrary ε for the tolerance on the values, and an existentially quantified δ for the required proximity of x.

DEFINITION 2.1（ε-δ）设函数 f 在 a 的某个去心邻域 0 < |x - a| < r 内有定义，L ∈ ℝ。若对任意 ε > 0，都存在 δ > 0，使得当 0 < |x - a| < δ 时恒有 |f(x) - L| < ε，则称 x 趋于 a 时 f(x) 的极限为 L，记作 lim (x → a) f(x) = L。Let f be defined on a punctured neighbourhood of a. If for every ε > 0 there is δ > 0 such that 0 < |x - a| < δ always implies |f(x) − L| < ε, then the limit of f at a is L.

三个细节决定了这个定义的全部技术含量。第一，ε 任意、δ 依赖 ε：改变的是"容许误差"，回应的是"需要多近"，因此 δ 一般是 ε 的函数，写作 δ(ε)。第二，条件是蕴含式：只要没有任何 x 落在去心 δ 邻域里，命题自动为真，所以定义不关心 f 在 a 点本身的行为。第三，邻域是去心的：这正是课堂反复强调的"极限与 f(a) 无关"在定义层面的来源，而不是一条需要另外记住的经验结论。

Three details carry all the technical weight. ε is arbitrary while δ depends on it, so δ is generally a function δ(ε); the condition is an implication, hence vacuously true when no x lies in the punctured δ-neighbourhood, so f(a) is irrelevant; and the neighbourhood is punctured, which is the definition-level reason behind the lecture's "the limit does not depend on f(a)" rather than a separate fact to memorise.

把定义当作一份"证明合约"，证明 lim f(x) = L 的固定流程就是：任取 ε > 0，从 |f(x) − L| < ε 出发反解出 0 < |x − a| < δ 的形式，取 δ 为该解的界。下面这个演示把这个流程做成了可以操作的模型：函数取 f(x) = 3x − 1，a = 2，此时 L = 5，反解给出 δ(ε) = ε / 3。

Read the definition as a proof contract: given ε > 0, solve the inequality |f(x) − L| < ε backwards for 0 < |x − a| < δ and take δ to be that bound. The demo below turns the procedure into a manipulable model for f(x) = 3x − 1, a = 2, L = 5, where the algebra gives δ(ε) = ε/3.

Take δ = ε/3; then 0 < |x − 2| < δ forces 3|x − 2| < ε, which is the definition.

技术提醒：本例中 δ 只依赖 ε，与 x 无关。当 f 非线性时（例如 f(x) = x²），反解出的界会依赖 x，标准做法是先限制 |x − a| ≤ 1 得到局部上界，再取 δ = min(1, ε/M)——这是 ε-δ 证明里最常用的一次技巧。

Technical note: a δ independent of x is the goal. For nonlinear f the algebraic bound depends on x, so the standard move is to first impose |x − a| ≤ 1, obtain a local bound M, and then take δ = min(1, ε/M).

Uniqueness and local properties唯一性与局部性质

定义一旦严格，就能立刻产出结论——而且这些结论在课堂的直观版本里只能"显然"，无法证明。下面三条是本课所有后续运算的地基，全部只用到定义 2.1。

Once the definition is rigorous, conclusions follow immediately — and these are exactly the statements that must remain "obvious" in an intuitive treatment. All three need nothing beyond Definition 2.1.

THEOREM 2.2（唯一性）若 lim (x → a) f(x) = L 且 lim (x → a) f(x) = M，则 L = M。极限存在则唯一。If both L and M are limits, then L = M.
PROOF设 L ≠ M，取 ε = |L − M| / 2 > 0。由定义存在 δ₁，使 0 < |x − a| < δ₁ 时 |f(x) − L| < ε；又存在 δ₂，使 0 < |x − a| < δ₂ 时 |f(x) − M| < ε。取 δ = min(δ₁, δ₂) > 0。因为 a 的去心邻域非空，取定其中一个 x，由三角不等式 |L − M| ≤ |L − f(x)| + |f(x) − M| < ε + ε = |L − M|，得到 |L − M| < |L − M|，矛盾。故 L = M。■
Assume L ≠ M, take ε = |L − M|/2, and use the triangle inequality on a common punctured neighbourhood to reach |L − M| < |L − M|, a contradiction.

注意证明里"去心邻域非空"这一步：它把蕴含式的空洞为真排除掉了。这正是为什么定义要求 f 在 a 的去心邻域内有定义。

THEOREM 2.3（局部有界性）若 lim (x → a) f(x) = L，则存在 δ > 0 与 M > 0，使得 0 < |x − a| < δ 时 |f(x)| ≤ M。即极限存在蕴含局部有界。Existence of a finite limit implies local boundedness.
PROOF取 ε = 1，存在 δ > 0 使 0 < |x − a| < δ 时 |f(x) − L| < 1。于是 |f(x)| ≤ |f(x) − L| + |L| < 1 + |L|。取 M = 1 + |L| 即得。■
Choose ε = 1 and add |L| to the bound.

由此可得一条重要的否定式判据：若 f 在 a 的任意去心邻域内都无界，则 lim (x → a) f(x) 不存在（有限极限意义下）。例如 1/x 在 x → 0 时无界，因此不存在有限极限——这与"极限为 ∞"是两件事。

THEOREM 2.4（保号性）若 lim (x → a) f(x) = L 且 L > 0，则存在 δ > 0，使 0 < |x − a| < δ 时 f(x) > L / 2 > 0。对 L < 0 同理。A positive limit forces f to stay positive nearby.
PROOF取 ε = L / 2 > 0，存在 δ > 0 使 |f(x) − L| < L / 2，即 −L/2 < f(x) − L < L/2，故 f(x) > L − L/2 = L/2 > 0。■
Use ε = L/2 and unpack the absolute-value inequality.

保号性的逆命题不成立：f(x) = x² 在 0 附近处处为正，但极限为 0，不是正数。它只在"严格符号"与"极限符号"之间存在单向传递，这也解释了后面夹逼定理为什么要求非严格不等式 ≤。

The converse fails: f(x) = x² is positive nearby yet has limit 0. Signs pass from limits to functions but not back — which is why the squeeze theorem is stated with non-strict inequalities.

One-sided limits, axiomatised单侧极限：定义、等价刻画与存在性定理

课堂上用 Heaviside 阶跃函数与开区间端点说明"必须引入单侧极限"，这是动机层面的说明。要在证明中使用，单侧极限需要自己的 ε-δ 定义，而且两侧定义中的邻域必须被截掉一半。

The lecture motivates one-sided limits with the Heaviside function and interval endpoints. To be usable in proofs they need their own ε-δ definitions — and the neighbourhood in each is cut in half.

DEFINITION 2.5（单侧极限）若对任意 ε > 0，存在 δ > 0，使当 a − δ < x < a 时 |f(x) − L| < ε，则称 f 在 a 处的左极限为 L，记 lim (x → a⁻) f(x) = L；把区间换成 a < x < a + δ 即得右极限 lim (x → a⁺) f(x) = L。Left and right limits replace the punctured neighbourhood by (a − δ, a) and (a, a + δ) respectively.
THEOREM 2.6（双侧 ⟺ 两侧）lim (x → a) f(x) = L 当且仅当 lim (x → a⁻) f(x) = lim (x → a⁺) f(x) = L。The two-sided limit exists and equals L exactly when both one-sided limits exist and equal L.
PROOF(⟹) 双侧定义中的 δ 对全部 0 < |x − a| < δ 成立，自然对 a − δ < x < a 与 a < x < a + δ 都成立，故两个单侧极限都等于 L。
(⟸) 设左右极限同为 L。取 ε > 0，由左极限存在 δ₁ > 0 使 a − δ₁ < x < a 时 |f(x) − L| < ε；由右极限存在 δ₂ > 0 使 a < x < a + δ₂ 时 |f(x) − L| < ε。取 δ = min(δ₁, δ₂)。若 0 < |x − a| < δ，则 x 必落在左段或右段之一，两种情况都给出 |f(x) − L| < ε。■
The forward direction is immediate; the converse takes δ = min(δ₁, δ₂) and splits on whether x lies left or right of a.

这条定理解释了课堂上的两个观察：Heaviside 函数在 0 点左极限 0、右极限 1，两侧不等，所以双侧极限不存在；定义在开区间 (1, 2) 上的函数在端点处只有一侧邻域落在定义域内，另一个单侧极限根本没有定义，因而"双侧等价"这条定理在端点处不可用。

Extension: monotonicity alone forces one-sided limits to exist. The proof uses the supremum principle applied to the set of values on (a, a + r). It is the reason "monotone and bounded" buys convergence, a fact reused later for sequences and improper integrals.

Limit laws, order and the squeeze theorem运算法则、序结构与夹逼定理

课堂列出了四则运算法则并提醒"前提是极限存在"，但没有证明。下面给出可证明的版本，并补上课堂没有涉及、但使用频率更高的序结构结论。

THEOREM 2.7（四则运算）设 lim f = A，lim g = B（同一极限点），则 lim (f ± g) = A ± B，lim (f · g) = A · B，且当 B ≠ 0 时 lim (f / g) = A / B。Limits split over sums, products and quotients, the last requiring a non-zero denominator limit.
PROOF（乘法）任取 ε > 0。写 f g − A B = (f − A) g + A (g − B)。由定理 2.3，存在 δ₀ > 0 与 M > 0 使 0 < |x − a| < δ₀ 时 |g(x)| ≤ M。取 ε₁ = ε / (2 max(M, 1))，有 δ₁ 使 |f − A| < ε₁；取 ε₂ = ε / (2 max(|A|, 1))，有 δ₂ 使 |g − B| < ε₂。令 δ = min(δ₀, δ₁, δ₂)，则 |f g − A B| ≤ |f − A||g| + |A||g − B| < ε/2 + ε/2 = ε。■
Insert and subtract A·B, then use local boundedness of g to control each term separately.
THEOREM 2.8（夹逼定理）若在 a 的某去心邻域内恒有 g(x) ≤ f(x) ≤ h(x)，且 lim g = lim h = L，则 lim f = L。If f is trapped between g and h, and both traps close on L, then f converges to L.
PROOF任取 ε > 0。由 lim g = L 存在 δ₁ 使 g(x) > L − ε；由 lim h = L 存在 δ₂ 使 h(x) < L + ε。取 δ = min(δ₁, δ₂) 与夹逼条件中成立的那个邻域半径，则 L − ε < g(x) ≤ f(x) ≤ h(x) < L + ε，即 |f(x) − L| < ε。■
Let both traps close within ε of L; the middle follows.

夹逼定理最实用的推论是课堂没有点明的一条：有界量乘无穷小仍是无穷小。若 |g(x)| ≤ M 在某去心邻域内成立，且 lim f = 0，则 −M|f(x)| ≤ f(x) g(x) ≤ M|f(x)|，两端都趋于 0，于是 lim f g = 0。

|g(x)| ≤ M, lim f(x) = 0 ⟹ lim f(x) g(x) = 0

The most useful corollary is unstated in the lecture: a bounded factor times an infinitesimal is still an infinitesimal. It is what separates x·sin(1/x) (limit 0) from sin(1/x) (no limit) even though both contain the same wild factor.

EXAMPLE 2.2
证明 lim (x → 0) x sin(1/x) = 0。
证明：对一切 x ≠ 0 有 |sin(1/x)| ≤ 1，故 0 ≤ |x sin(1/x)| ≤ |x|。由 lim (x → 0) |x| = 0 与夹逼定理得 lim |x sin(1/x)| = 0，从而 lim x sin(1/x) = 0（因为 |u| → 0 ⟺ u → 0）。不需要估计 sin(1/x) 本身，也不需要它收敛。■

The sequential criterion and proving non-existence序列刻画（海涅定理）与极限不存在的证明

课堂提出了"找两条都趋于 a 的序列、若像不同则极限不存在"的方法，称其为"震荡极限的判定逻辑"。它是一个定理的直接应用，定理本身值得单独记住。

THEOREM 2.9（Heine，极限的序列刻画）设 f 在 a 的去心邻域内有定义，则 lim (x → a) f(x) = L 当且仅当对任意满足 xₙ → a 且 xₙ ≠ a 的序列，都有 f(xₙ) → L。f has limit L at a iff every sequence approaching a (with xₙ ≠ a) is mapped to a sequence converging to L.
PROOF(⟹) 设 lim f = L。任取 ε > 0，由定义取 δ > 0。因 xₙ → a，存在 N 使 n > N 时 0 < |xₙ − a| < δ，于是 |f(xₙ) − L| < ε，即 f(xₙ) → L。
(⟸) 用逆否命题。若 lim f ≠ L，则存在 ε₀ > 0，使得对每个 δ = 1/n 都存在 xₙ 满足 0 < |xₙ − a| < 1/n 而 |f(xₙ) − L| ≥ ε₀。这样的序列满足 xₙ → a 且 xₙ ≠ a，但 f(xₙ) 不收敛到 L，与题设矛盾。■
The forward direction is a direct ε-δ chase; the converse is proved by contraposition, building a bad sequence out of the failure of the definition with δ = 1/n.

把定理反向使用，就得到否定判据：只要找到两条序列 xₙ, yₙ → a 使 f(xₙ) 与 f(yₙ) 收敛到不同的值，或者 f(xₙ) 干脆不收敛，即可断定极限不存在。这比直接否定 ε-δ 定义容易得多，因为构造序列是构造性的工作。

Used in reverse, the theorem is a disproving device: two sequences converging to a with images converging to different values settle the matter. Constructing sequences is far easier than negating an ε-δ statement directly.

EXAMPLE 2.3
用海涅定理证明 lim (x → 0) sin(1/x) 不存在。
证明：取 xₙ = 1/(2nπ + π/2)，则 xₙ → 0 且 xₙ ≠ 0，而 sin(1/xₙ) = sin(2nπ + π/2) = 1 → 1。再取 yₙ = 1/(2nπ)，同样 yₙ → 0，而 sin(1/yₙ) = sin(2nπ) = 0 → 0。同一极限点得到两个不同的极限值，由定理 2.9 的逆否形式，极限不存在。■

提高难度（拓展）：定理 2.9 的用处不止于否定。它是把"函数极限"与"数列极限"两套理论互译的通道——凡是数列极限里成立的结论（单调有界、柯西准则、施托尔茨定理）都可以借它搬过来。反过来，它也解释了一个初学常见错觉：逐点验证了再多的序列都不足以证明极限存在，因为定义要求"任意"，而任意序列是无限多的对象。

Extension: Heine's criterion is a translator between function limits and sequence limits, so every sequence theorem — monotone convergence, Cauchy's criterion, Stolz — becomes available. It also explains a common illusion: checking many sequences can never prove existence, because the definition quantifies over all of them.

Infinite limits, infinitesimals and orders of smallness无穷极限、无穷小与阶的估计

课堂用"一千万、一个亿都不够大"描述趋于无穷，这是准确的直观，但"无穷极限"与"极限不存在"的关系必须讲清：在实数极限的框架下，lim = ∞ 是一种特殊的极限不存在，它的价值在于记录了失效的方式。它的定义同样可以量化，只是 ε 被换成了任意大的 M。

The lecture describes divergence as "ten million is not enough". That intuition is right, but the relation to non-existence must be stated: in the real framework, lim = ∞ is a special kind of non-existent limit that records how it fails. Its definition quantifies over an arbitrary large M instead of an ε.

DEFINITION 2.10（无穷极限）若对任意 M > 0，存在 δ > 0，使得当 0 < |x − a| < δ 时恒有 f(x) > M，则记 lim (x → a) f(x) = +∞；把 f(x) > M 换成 f(x) < −M 即得 lim (x → a) f(x) = −∞。相应地，双侧无穷极限成立的充要条件是左右两侧的无穷极限同号且都存在。Replace the ε-tolerance by "exceeds any M", and require both one-sided infinite limits to agree in sign.
THEOREM 2.11（倒数关系与无穷小的有界性）若 lim (x → a) f(x) = ±∞，则 lim (x → a) 1/f(x) = 0；反之若 f(x) → 0 且在某去心邻域内 f(x) ≠ 0，则 1/|f(x)| → +∞。Infinite limits and infinitesimals are reciprocals.
PROOF（前一半）任取 ε > 0。令 M = 1/ε。由 lim f = +∞ 存在 δ > 0 使 0 < |x − a| < δ 时 f(x) > M = 1/ε，于是 0 < 1/f(x) < ε，即 |1/f(x)| < ε。■
Set M = 1/ε and invert.

The two fundamental limits, derived两个重要极限的严格推导

课堂把 lim (x → 0) sin x / x = 1 作为"必须记住的事实"，并说明严格推导要等夹逼原理。现在两个工具都齐了，可以补上这个推导——它是整门课第一个真正需要几何直觉的极限，也是"面积夹逼"这一整套技术的原型。

The lecture presents lim (x → 0) sin x / x = 1 as a fact to memorise. With the squeeze theorem now available, the derivation can be completed — and it is the prototype of every area-squeezing argument that follows.

THEOREM 2.12（第一重要极限）lim (x → 0) sin x / x = 1。由等价记号即 sin x ~ x（x → 0）。The first fundamental limit, equivalent to sin x ~ x.
PROOF先设 0 < x < π/2。由扇形与三角形面积比较得 sin x < x < tan x。除以 sin x > 0 得 1 < x / sin x < 1 / cos x，取倒数得 cos x < sin x / x < 1。因 lim (x → 0⁺) cos x = 1（由 cos 的连续性），由夹逼定理得右极限为 1。又 sin x / x 是偶函数（sin(−x)/(−x) = sin x / x），故左极限同为 1，由定理 2.6 得双侧极限为 1。■
Compare areas, divide by sin x, take reciprocals, apply the squeeze theorem for the right-hand limit, then use evenness for the left.
THEOREM 2.13（第二重要极限）数列 aₙ = (1 + 1/n)ⁿ 单调递增且有上界，故收敛；其极限定义为 e，即 lim (n → ∞)(1 + 1/n)ⁿ = e，且 lim (x → 0⁺)(1 + x)^{1/x} = e。The sequence is increasing and bounded above; its limit defines e.
PROOF（骨架）用二项式展开得 aₙ = Σ_{k=0}^{n} C(n,k) / nᵏ，逐项比较可证 aₙ < a_{n+1}（单调增）；再用 (1 + 1/n)ⁿ < 1 + 1 + 1/2! + … + 1/n! < 3 得它有上界。由单调有界原理，aₙ 收敛，记极限为 e。■
Binomial expansion gives monotonicity term by term; the same expansion gives 3 as an upper bound; monotone convergence finishes the job.

提高难度（拓展）：定理 2.13 给出 e 的存在性，但完全没有告诉你 e 是多少——这正是"存在性定理"与"计算方法"的分工。实际计算 e 需要用级数 e = Σ 1/k!，而把这两个极限与级数联系起来，正是下一阶段 Taylor 展开的任务。此外，由定理 2.12 可以直接推出 tan x ~ x、arcsin x ~ x、1 − cos x ~ x²/2，推导方式都是"化为 sin x / x 或 sin²(x/2)/(x/2)² 的形式"——这解释了为什么课上的速查表不需要背诵，只需要从一条极限推出。

Extension: Theorem 2.13 establishes that e exists without computing it; the series e = Σ 1/k! supplies the value. And every entry of the lecture's equivalence table is a one-line consequence of sin x / x, obtained by rewriting in terms of sin of a half-angle.

Continuity and the classification of discontinuities连续性与间断点分类

课堂反复强调"极限与 f(a) 无关"，把它翻译成连续性的语言就得到本课与下一章之间的桥：连续性不是新的概念，而是"极限恰好等于函数值"这一巧合。f 在 a 连续 ⟺ lim (x → a) f(x) = f(a)。由此立刻得到连续性的三条判据，缺一不可：f 在 a 有定义、极限存在、两者相等。

Translated into continuity, the lecture's emphasis becomes the bridge to the next chapter: f is continuous at a exactly when the limit equals f(a). Three conditions must hold together — defined, limit exists, equal.

THEOREM 2.14（连续与单侧）f 在 a 连续 ⟺ f 在 a 既左连续又右连续，即 lim (x → a⁻) f(x) = f(a) = lim (x → a⁺) f(x)。Continuity is equivalent to continuity from both sides.

补充（拓展）：这三个条件还给出一个常用技巧——判断连续性时，先把 f(a) 与 lim f 分别算出来再比较，而不是直接算极限。课堂上 (sin x)/x 与 (x − 1)/(x² − 1) 两个例子都是"极限存在但 f(a) 无定义"，属于可去间断；只要把 a 点的值补成极限值，函数立刻在该点连续。这一步称作连续延拓。

Extension: a practical habit — compute f(a) and lim f separately, then compare. Both lecture examples are removable: defining f(a) to be the limit performs the continuous extension.

Harder problems提高难度：综合例题与练习

以下题目超出课堂范围，但每一道都能只用本课的定理完成——这是检验"是否真的掌握了本课"的标准。建议先自己写完整证明，再对照解答要点。

EXERCISE 1 · ε-δ
用定义证明 lim (x → 1) (x² + 1) = 2。
要点：|x² + 1 − 2| = |x − 1||x + 1|。先限制 |x − 1| < 1，则 1 < x < 2，故 |x + 1| < 4。取 δ = min(1, ε/4)，则 |x² − 1| < 4 · ε/4 = ε。关键动作是"先局部界定，再吸收常数"。
EXERCISE 2 · 夹逼
证明 lim (x → 0⁺) x · ⌊1/x⌋ = 1（⌊·⌋ 为取整函数）。
要点：由取整不等式 1/x − 1 < ⌊1/x⌋ ≤ 1/x，同乘 x > 0 得 1 − x < x⌊1/x⌋ ≤ 1。两端都趋于 1，由夹逼定理得结论。这题说明"震荡/跳跃"的因子只要被代数不等式压住，极限仍然存在。
EXERCISE 3 · 高阶无穷小
求 lim (x → 0) (tan x − sin x) / x³。
要点：tan x − sin x = sin x (1/cos x − 1) = sin x (1 − cos x)/cos x。代入等价关系 sin x ~ x、1 − cos x ~ x²/2、cos x → 1，得极限为 1/2。若直接把 tan x 与 sin x 都换成 x，会得到 0/0 之外错误的 0，这正是课堂上强调"加减不能替换"的最短反例。
EXERCISE 4 · 单侧与指数
讨论 f(x) = x / (1 + e^{1/x}) 在 x = 0 处的单侧极限与连续性。
要点：当 x → 0⁺ 时 1/x → +∞，故 e^{1/x} → +∞，分母主导，f(x) → 0；当 x → 0⁻ 时 1/x → −∞，e^{1/x} → 0，故 f(x) → x/1 → 0 也成立。两侧极限都为 0，因此极限存在且为 0；但 f 在 0 处无定义，属于可去间断，补充定义 f(0) = 0 即得连续延拓。
EXERCISE 5 · 幂指函数
求 lim (x → 0⁺) xˣ。
要点：写成 xˣ = e^{x ln x}。由夹逼：对 0 < x < 1，取 n 使 1/(n+1) ≤ x < 1/n，则 |x ln x| ≤ (ln n)/n → 0，故 x ln x → 0。由 eˣ 的连续性，xˣ → e⁰ = 1。核心是"用夹逼把 x ln x 压到 0"，而不是直接代入。
EXERCISE 6 · 序列刻画
证明 f(x) = sin(1/x) 在 x → 0 时既没有有限极限，也不趋于无穷。
要点：有限极限用定理 2.9 的两条序列否定（如例 2.3）。"不趋于无穷"需要另一组证据：取 zₙ = 1/(nπ)，则 f(zₙ) = sin(nπ) = 0，函数值沿该序列恒为 0，不可能超过任意的 M，因此也不满足定义 2.10。两个结论合起来说明这个函数在 0 处属于震荡型间断——它同时否定了极限存在与无穷极限两种可能。

4 · A limit ignores the value at the point4 · 极限与函数在该点的取值无关

函数在 x→a 时的极限只反映"自变量趋近 a 时函数值的变化趋势"，与 f(a) 是否存在、等于多少完全无关。由此得到一条极有用的规则：若两个函数在 a 的某个去心邻域内完全相等，则它们在该点的极限相同——这正是约分、通分、变量代换这些操作的合法性来源。

The limit of f as x → a reflects only the trend as x approaches a; it is independent of whether f(a) exists and of its value. Hence the rule that two functions equal on a punctured neighbourhood of a have the same limit there — the justification for cancelling, combining fractions and substituting variables.

顺带澄清一个常见误解："去心邻域内相等"要求的是整段邻域上相等，而不是"在 a 点附近看着差不多"。仅在某点相等、或在若干孤立点上相等都不够。

5 · Order preservation5 · 保序性

若在 a 的某去心邻域内恒有 f(x) ≤ g(x)，且两者在 x→a 时极限都存在，则 lim f(x) ≤ lim g(x)。

难度往上走一层——这是本课最值得记住的陷阱：前提里的"≤"不能加强为"<"。即便 f(x) < g(x) 处处严格成立，极限仍可能相等。反例：f(x)=0，g(x)=|x| 在 x≠0 时恒有 f < g，但两者在 x→0 时极限都是 0。原因很直观：极限描述的是"趋于"的过程，严格的大小关系在取极限这一步会被"磨平"。

If f(x) ≤ g(x) on a punctured neighbourhood of a and both limits exist, then lim f ≤ lim g. The subtle point — and the trap worth memorising — is that the hypothesis cannot be strengthened to a strict inequality: take f(x) = 0 and g(x) = |x|; then f < g for every x ≠ 0, yet both limits at 0 equal 0. A strict comparison does not survive the passage to the limit.

与保序性配套使用的是保号性：若 lim f(x) = L > 0，则在 a 的某去心邻域内 f(x) > 0（把 0 换成任何小于 L 的数同样成立）。两者常被合起来用于证明和估计。

Companion result: sign preservation — if lim f(x) = L > 0, then f(x) > 0 on some punctured neighbourhood of a, and the same holds with 0 replaced by any number below L.

6 · The squeeze theorem6 · 夹逼准则

若在 a 的某去心邻域内恒有 f(x) ≤ g(x) ≤ h(x)，且 x→a 时 f 与 h 的极限都等于同一个数 L，则中间的 g 在 x→a 时的极限也等于 L。

两点补充：第一，前提必须写在去心邻域上，不能只在一列点上成立；第二，"两侧极限相等"是充分条件——只要能找到任何一对满足条件的上下界即可，不必是最优界。这一点在估计时非常实用：常常故意用一个更宽松但更好算的界。

Two remarks. The hypotheses must hold on a punctured neighbourhood, not merely at a sequence of points; and equal outer limits are sufficient — you only need some pair of bounds, not the tightest ones, which is what makes the theorem so useful for estimation.

课堂上用夹逼处理了有界函数乘无穷小：x→0 时 x²sin(1/x) 的极限。因为 |sin(1/x)| ≤ 1，所以 −x² ≤ x²sin(1/x) ≤ x²，两侧极限都是 0，故极限为 0。

The standard application: since |sin(1/x)| ≤ 1, we have −x² ≤ x²sin(1/x) ≤ x², and both outer functions tend to 0, forcing the middle one to 0 as well.

8 · The ε–δ definition and its 6 × 4 variants8 · ε-δ 定义与 6×4 种变体

严格定义：对任意给定的 ε > 0，都存在 δ > 0，使得当 0 < |x − a| < δ 时恒有 |f(x) − L| < ε，则称 x→a 时 f(x) 的极限为 L。其中 0 < |x − a| 表示取去心邻域，a 点本身的取值与定义无关；δ 依赖于 ε，只要存在一个即可，不必是最优的。

Rigorous definition: for every ε > 0 there is δ > 0 such that 0 < |x − a| < δ implies |f(x) − L| < ε. The condition 0 < |x − a| marks a punctured neighbourhood, so the value at a is irrelevant; δ depends on ε and any admissible δ will do.

And the "six limit processes × four kinds of limit value" should be read as 6 × 4 = 24 definition variants, not two independent lists; moreover the quantity controlling how close x gets is not always called δ — for x → ∞ one uses X.

1 · Real numbers: completeness and distance1 · 实数系：完备性与距离

有理数与无理数都是无穷集合，但无穷与无穷不一样：区间 (0,1) 里的实数比有理数"多得多"。课堂上的原话是——"你的视野只局限在有理数范围里，你看不到无理数，就像晚上看星星，你只看到那几个亮的，后面还有浩瀚宇宙里无穷多的星星。"

The rationals and the irrationals are both infinite, but not all infinities are equal: there are far more reals than rationals in (0,1). As the lecturer put it, inside the rationals you only see the few bright stars — the vast majority of the sky is invisible.

2 · The three conditions for continuity2 · 点连续的三个条件

函数 f 在点 a 连续，当且仅当以下三条同时成立：

① 有定义：f(a) 存在（a 在定义域内）。 ② 极限存在：limx→a f(x) 存在（左右极限存在且相等）。 ③ 二者相等：limx→a f(x) = f(a)。

f is continuous at a iff (1) f(a) exists, (2) the two-sided limit exists, and (3) they are equal. Fail any one and the point is a discontinuity.

与极限的关键差别（本课最容易被忽略的一点）：讨论极限只需要 a 的去心邻域有定义（a 点本身可以没有定义）；讨论连续则要求 a 的整个邻域都有定义，而且 a 点自己必须有定义。这正是"极限存在但函数不连续"这种情形能够存在的原因。

The difference that decides everything: a limit needs only a punctured neighbourhood, while continuity needs a full neighbourhood and a defined value at the point. That is exactly why a limit can exist while the function is discontinuous there.

几何意义：自变量在 a 附近做微小变动时，函数值只发生微小变化——所以在这点附近，曲线可以近似地用一条水平线段 y = f(a) 替代。这就是"图像没有断开"的精确含义。

5 · Continuity on an interval5 · 区间上的连续性

开区间 (a,b) 上连续：函数在该区间的每一个内点都连续即可。

闭区间 [a,b] 上连续：需要在"开区间内每点连续"的基础上，再加上左端点右连续、右端点左连续。原因是端点的外侧没有定义，根本无法讨论"整个邻域"，所以只能用单侧极限来判定。

On an open interval every interior point must be continuous. On a closed interval you additionally require right-continuity at the left endpoint and left-continuity at the right endpoint — outside an endpoint there is no neighbourhood to speak of, so only one-sided limits make sense.

6 · Which functions are continuous, and why substitution works6 · 哪些函数连续，以及代入法为什么成立

四则运算保持连续：若 f、g 都在 a 点连续，则 f±g、f·g 在 a 点连续，f/g 在 g(a) ≠ 0 时也在 a 点连续。这条结论可以直接由极限的四则运算法则推出来——这也解释了"连续点处求极限可以直接代入"的原理：代入法不是技巧，而是连续性的定义。

Sums, differences, products and (where the denominator is non-zero) quotients of functions continuous at a are continuous at a. This follows from the algebra of limits — and it explains why direct substitution works: substitution is the definition of continuity, not a trick.

拓展一层（原笔记未提的更一般结论）：不仅有理函数在其定义域内连续，一切初等函数在其定义区间内都是连续的——多项式、有理函数、幂函数、指数函数、对数函数、三角函数、反三角函数，以及它们的复合。所以求这类函数的极限时，先看极限点是否落在定义区间内，是就直接代入。

A more general fact the notes omitted: every elementary function is continuous on its interval of definition — polynomials, rational functions, powers, exponentials, logarithms, trigonometric and inverse trigonometric functions, and compositions of them. So for such a function, check first whether the limit point lies inside the interval of definition; if it does, substitute.

再往上走一层（下次课的伏笔）：闭区间上的连续函数有三条很硬的结论——有界性定理（必有界）、最值定理（一定取到最大值和最小值）、介值定理（能取到介于两端函数值之间的任何数，零点定理是它的特例）。这三条是后续中值定理与积分理论的支柱。另外提醒一句：连续不一定可导，例如 |x| 在 0 处连续但左右导数不相等。

Three results that carry the rest of the course: on a closed interval a continuous function is bounded, attains its maximum and minimum, and takes every value between its endpoint values (the intermediate value theorem, with the zero theorem as a special case). Also note: continuity does not imply differentiability — |x| is continuous at 0 but has no derivative there.

2 · The ε-δ check for √x2 · 根式函数的 ε-δ 验证

设 x₀ > 0，要证 lim (x → x₀) √x = √x₀。任取 ε > 0，把差有理化：

|√x − √x₀| = |x − x₀| / (√x + √x₀) ≤ |x − x₀| / √x₀

因为 √x ≥ 0，分母 ≥ √x₀ > 0，所以取 δ = ε·√x₀ 即可：当 |x − x₀| < δ 时 |√x − √x₀| < ε。证明完成。关键动作是把"根号之差"变成"自变量之差"再乘一个可控因子——这个套路在后续证明各种函数连续性时会反复出现。

为什么 x₀ = 0 要单独说：上面的不等式用了分母 ≥ √x₀ > 0。当 x₀ = 0 时分母只有 √x，不能这样放缩。而 0 是定义域的左端点，邻域只有右半边，所以 √x 在 0 处只有右连续——这不是缺陷，而是定义域边界的必然结果，也正是第四课引入左右连续的原因。

Rationalise the difference, bound the denominator by √x₀, and take δ = ε√x₀. The trick — turn a difference of roots into a difference of the variable times a controlled factor — returns constantly. At x₀ = 0 the bound fails and the domain has only one side, so √x is merely right-continuous there.

3 · Algebra of continuity, and which functions are continuous3 · 连续性的四则运算，以及哪些函数连续

四则运算性质：若 f 与 g 在 a 点都连续，则 f ± g、f · g、常数 · f 在 a 点连续；f / g 在 g(a) ≠ 0 时也在 a 点连续。

为什么除法要多一个条件：因为 g(a) = 0 时 f/g 在 a 点根本没有定义，谈连续性无从谈起。这条限制和第三课"极限的四则运算要求分母极限不为零"是同一件事。

区间连续：若 f 在区间 I 的每一点都连续，就称 f 是 I 上的连续函数。有理函数就是最典型的例子——它在自己的定义域内处处连续（定义域之外的点和它无关）。

四类常见的连续函数（原笔记的清单要补两项）：

类别例子在哪儿连续
多项式3x³ − 2x + 1整个实数轴

4 · Composition: the limit travels through4 · 复合函数：极限可以穿过去

这是本课技术上最有价值的一条，课堂讲得很清楚，值得分成两个定理来记：

定理 5.1（极限穿入连续函数）设 lim (x → a) g(x) = b，且 f 在 b 点连续，则 lim (x → a) f(g(x)) = f(b) = f( lim (x → a) g(x) )。注意：g 只需要有极限，不需要连续。If g has limit b at a and f is continuous at b, the limit passes inside: lim f(g(x)) = f(lim g(x)).
定理 5.2（复合的连续性）若 g 在 a 点连续且 f 在 g(a) 点连续，则复合函数 f∘g 在 a 点连续。Continuous outside, continuous inside, continuous composition.

为什么第一条如此好用：它把"求一个复杂极限"变成"先求内层的极限，再把这个数交给外函数"。例如 lim (x → 0) e^((sin x)/x) —— 内层 (sin x)/x → 1，而 e^u 在 1 处连续，所以整个极限是 e¹ = e。不需要任何新的极限技巧。

为什么"外函数必须连续"不能省：课堂特意点了这一条——如果 f 只在 b 处有极限而不连续，结论就不成立。最干净的反例是：

f(u) = 1（当 u = 0），f(u) = 0（当 u ≠ 0）；g(x) = x lim (x → 0) g(x) = 0，但 lim (x → 0) f(g(x)) = lim (x → 0) f(x) = 0 ≠ f(0) = 1

问题出在：求 lim f(g(x)) 时 x 永远不等于 a，所以 g(x) 永远取不到 b，f 在 b 点的取值就完全不影响结果；而 f(b) 用的正是那个值。要弥合这个缝，只能靠"f 在 b 点连续"——它的定义就是"极限值 = 函数值"。这一句话就是这条定理的全部内容。

The gap is that x never equals a, so g(x) never reaches b; f(b) therefore cannot influence the composite limit, while the right-hand side uses it. Continuity at b is exactly the statement that closes the gap.

5 · Limits of power-exponential functions5 · 幂指函数的极限

形如 f(x)^g(x) 的函数（底和指数都随 x 变）叫幂指函数。课堂上给出的方法是：取自然对数，把幂变成乘。

f(x)^g(x) = e^( g(x) · ln f(x) ) （要求 f(x) > 0） 所以 lim f^g = e^( lim [ g · ln f ] )

推导链：对数把指数拉下来成为乘法 → 指数函数 e^u 在任意点连续 → 用定理 5.1 把极限穿进去 → 只要算出指数上那个普通极限即可。整个方法的可靠性完全建立在"e^u 连续"这一条上，这正是第 4 节的价值。

它主要用来处理三类未定式：1^∞、0^0、∞^0。其中 1^∞ 最常见，标准结果是：

若 f(x) → 1 且 g(x) → ∞，令 L = lim g(x)·(f(x) − 1)，则 lim f(x)^g(x) = e^L 例：(1 + x)^(1/x) → e¹ = e (1 + 2x)^(1/x) → e²

第二条公式里用到了等价无穷小 ln(1+t) ~ t（第 2 课的表），它把 ln f = ln(1 + (f−1)) 简化成 f − 1。这就是"等价无穷小只在乘除中可用"的一个正当用法。

Write f^g as e^(g ln f); since e^u is continuous the limit passes inside, and the problem collapses to an ordinary limit on the exponent. The common case is 1^∞, where L = lim g(f − 1) and the answer is e^L.

6 · Classifying discontinuities, in practice6 · 动手判定间断点

课堂最后用一批例题练"判断间断点类型"。判定流程只有三步，值得固化成习惯：

第一步：找可疑点——函数无定义的点（分母为零、偶次根号为负、对数真数非正、tan 的奇点）。 第二步：算左右极限——分别求 x → a⁻ 与 x → a⁺ 的极限。 第三步：对号入座——两侧都有限且相等但 ≠ f(a)（或 f(a) 无定义）是可去；两侧不等但都为有限值是跳跃；至少一侧无穷是无穷；极限不存在且不为无穷是振荡。

一处必须更正的地方：原笔记把间断点归纳为三类（可去、无穷、跳跃），并通过"连续三要素不满足"来推导。这个推理有一个漏洞：三要素的失效方式并不只有三种。sin(1/x) 在 0 处既没有有限极限、也不趋于无穷、左右极限更谈不上"存在但不等"——它属于第四类：振荡间断点。第四课已经按四类讲，这一课应当保持一致。

The notes reduce discontinuities to three types by arguing from the three conditions of continuity. That argument has a gap: failing the conditions does not exhaust the possibilities. sin(1/x) at 0 fits none of the three, which is why the fourth type — oscillating — must be listed.

课堂例题：tan x 的所有 x = kπ 点。x = 0 处 tan x ~ x，两侧都趋于 0，而 f(0) 无定义 → 可去间断；其余 k ≠ 0 的 kπ 点两侧分别冲向 +∞ 与 −∞ → 无穷间断。这个例子同时考了等价无穷小、单侧极限与分类，很值得自己重做一遍。

7 · The four theorems on a closed interval7 · 闭区间上的四大定理

这是本课的高潮，也是最"深刻"的一段。四条定理有完全相同的两个前提：定义域是闭区间 [a, b]，函数在它上面连续。

定理结论缺了前提会怎样
最值定理f 在 [a, b] 上必取到最大值 M 与最小值 my = x 在 (0,1) 上取不到最值；|x|/x 在 [−1,1] 上不连续，也取不到
有界性定理f 在 [a, b] 上一定有界1/x 在 (0,1) 上连续但无界
零点存在定理若 f(a)·f(b) < 0，则存在 ξ ∈ (a, b) 使 f(ξ) = 0[−1,1] 上令 f(±1) 异号、中间跳变，就没有零点
介值定理若 f(a) ≠ f(b)，则介于两者之间的任何 μ 都能被取到同上；或定义域开区间时端点附近的 μ 取不到

它们之间的关系：最值定理 ⟹ 有界性定理（取到最值自然有界）；介值定理 ⟹ 零点存在定理（取 μ = 0）。反方向也能补：课堂指出零点定理与介值定理在闭区间连续的前提下互相可推——由介值到零点是直接取 μ = 0；由零点到介值则是构造辅助函数 F(x) = f(x) − μ，再用零点定理。所以"等价"的说法在该前提下是对的，但要记住零点定理额外要求两端异号，介值定理只要求两端不等。

The four theorems share the same two hypotheses. Max-value implies boundedness (attaining extremes gives bounds); IVT implies the zero theorem (take μ = 0). The converse uses the auxiliary function F(x) = f(x) − μ, so the two really are interchangeable on a closed interval — with the caveat that the zero theorem asks for opposite signs while the IVT only asks for unequal values.

课堂讲的最值定理证明思路：先用确界原理（第 4 课的实数完备性！）取出值域的上确界 M，再证明存在 ξ 使 f(ξ) = M。这一步不能省——上确界只是"最小的上界"，未必被取到；正是因为定义域是闭的，才能用区间套或序列紧性把取到 M 的那个点"抓"住。"闭"在这里不是装饰，而是把极限点留在区间内的保证。

The proof of the extreme-value theorem uses the supremum principle from Lesson 4, then shows the supremum is attained. Closedness is what keeps the limiting point inside the interval — it is not decoration.

8 · Why both hypotheses are needed8 · 为什么两个前提都省不掉

课堂用两个反例把这件事钉死了。建议把它们当成"考试里举反例的模板"背下来：

去掉的前提反例失效的结论
闭 → 开y = x 在 (0, 1)取不到最大值与最小值（只能无限接近 1 和 0）
闭 → 开（无界）y = 1/x 在 (0, 1)连续但无界
闭 → 半开y = x 在 (0, 1]最小值取不到
连续 → 不连续f(x) = x（x ≠ 1）；f(1) = 5 在 [0, 2]最大值仍是 5（被"跳"出来了），但介值性质失效
连续 → 不连续（跳跃）[−1, 1] 上 f(x) = −1（x < 0）、f(x) = 1（x ≥ 0）两端异号，却没有零点——零点定理失效

深层原因（课堂提到的那句很值得记）：非闭区间对"取极限"这个运算不封闭。开区间 (0,1) 里的数列 1/2, 1/3, 1/4, … 每一项都在区间内，但它趋于的 0 不在区间里——极限跑掉了。而闭区间 [0,1] 不会：只要点都在里面，它们的极限点也一定还在里面（这叫闭集对极限封闭）。

课堂把它类比成"有理数不完备"：本质上是一回事——一个数系或集合能不能容纳自己产生的极限。第 4 课讲实数完备性时用的是同一个问题，这一课换成了区间的语言。

The deep reason: an open interval is not closed under taking limits. The sequence 1/2, 1/3, … lives inside (0,1) but its limit 0 does not. A closed interval keeps its limit points, which is exactly what the four theorems need. The lecturer's analogy with the incompleteness of the rationals is the same phenomenon in different clothing.

9 · The auxiliary-function trick9 · 构造辅助函数的套路

要证"存在 ξ 使 g(ξ) = c"，标准做法分两步，几乎不需要灵感：

第一步：移项。把等式变成 F(x) = g(x) − c = 0 的形式，把"取值问题"翻译成"零点问题"。 第二步：验条件。证明 F 在闭区间上连续，再在区间内找两点使 F 异号——不必是端点，课堂上特意强调了这一点。
EXAMPLE 5.1
证明方程 x = cos x 在 (0, π/2) 内有解。
证明：令 F(x) = x − cos x，它在 [0, π/2] 上连续（多项式与余弦之差）。计算端点：F(0) = 0 − 1 = −1 < 0，F(π/2) = π/2 − 0 = π/2 > 0。两端异号，由零点存在定理，存在 ξ ∈ (0, π/2) 使 F(ξ) = 0，即 ξ = cos ξ。■
EXAMPLE 5.2
用构造辅助函数的方法证明介值定理（设已知零点存在定理）。
证明：设 f 在 [a, b] 连续，μ 介于 f(a) 与 f(b) 之间。令 F(x) = f(x) − μ。F 连续，且 F(a) = f(a) − μ 与 F(b) = f(b) − μ 异号（因为 μ 夹在 f(a)、f(b) 之间）。由零点存在定理，存在 ξ ∈ (a, b) 使 F(ξ) = 0，即 f(ξ) = μ。■
This is exactly the two-step template: shift the equation into a zero-finding problem, then verify the hypotheses.
